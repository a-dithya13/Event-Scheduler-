# Event Scheduler

A web-based event scheduling application designed to help users create, manage, and keep track of their events.

## Overview

Event Scheduler is a frontend-focused web application built to simplify personal event management. Users can create and manage events through a simple interface, with event information stored locally in the browser.

The project was developed as part of my early web development work and helped me practice JavaScript, DOM manipulation, browser storage, and building interactive user interfaces.

## Features

- Create and manage events
- View scheduled events
- Store event information using Local Storage
- User login and signup interface
- Event notifications
- Interactive event management
- Persistent data between browser sessions

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How It Works

The application allows users to enter event details through the interface and stores the relevant information in the browser using Local Storage.

When the application is reopened, previously stored event information can be retrieved from Local Storage, allowing the user to continue managing their events without requiring a backend database.
